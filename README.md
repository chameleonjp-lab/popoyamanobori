# ぽぽ山のぼり

iPhone SE（横向き 568×320px）で遊べる、スマホ用の2D横スクロールブラウザゲームです。添付キャラクター案をもとに、たぬき修験者「ぽぽ」と妖怪敵キャラクターをCanvasで描画します。

## 遊び方

- `index.html` をブラウザで開きます。
- タップまたは「跳」ボタンでジャンプします。
- 長押し後に離す、または「吹」ボタン / `Z` キーで法螺貝攻撃をします。
- 護符を集め、妖怪をかわしながら1000m先の山頂を目指します。

## 開発メモ

外部ライブラリ不要の静的HTML/CSS/JavaScript構成です。画面はiPhone SEの横向き解像度に合わせた`568×320`のCanvasを基準にしています。
